# 2× NVIDIA Tesla V100

**This host** is two Tesla V100-SXM2-16GB (Volta, sm_70). Strata runs here on the experimental **CUDA 12** engine. CUDA 13 dropped Volta and will not start on these cards.

Do not copy a Blackwell / RTX `.env` (`…-cuda13`) onto this box.

Official references: [NVIDIA_V100.md](https://github.com/Niko1221/Strata/blob/main/docs/NVIDIA_V100.md), [OLDER_GPUS.md](https://github.com/Niko1221/Strata/blob/main/docs/OLDER_GPUS.md), [MULTI_GPU.md](https://github.com/Niko1221/Strata/blob/main/docs/MULTI_GPU.md), [DOCKER.md](https://github.com/Niko1221/Strata/blob/main/docs/DOCKER.md).

## This machine

| | |
| --- | --- |
| Cards | 2× Tesla V100-SXM2-16GB (16 GiB each, sm_70) |
| Driver | 580.x (above the CUDA 12 floor of **575.51**) |
| RAM | ~62 GB |
| Topology | PCIe via host bridge; NVLink inactive. Strata’s split does not need NVLink |
| Profile | `.env.v100.example` → `.env` |
| Image | `ghcr.io/niko1221/strata:0.2.8-cuda12` |
| Default pack | Qwen3.8-Flash-Next **IQ2_XS**, 32K, `VISION=cpu`, `GPU=0,1` |
| API id | `qwen3.8-flash-next-iq2_xs` |
| First download | ~74 GB (model ~68 GB + MTP draft ~5 GB + picture reader ~1 GB) |

A Blackwell / RTX PRO box uses `.env.example`, the CUDA 13 image, and **`GPU=0`**. Leaving `GPU` unset in this wrapper still injects `0,1` and Strata exits 6 on that one-card machine.

## What the scripts do

After copying `.env.v100.example` to `.env`:

| Piece | Behaviour |
| --- | --- |
| `./scripts/install-native.sh` | Official Terminal. First native launch pulls the **CUDA 12** engine because the cards are Volta |
| `STRATA_IMAGE` | `ghcr.io/niko1221/strata:0.2.8-cuda12` |
| `GPU=0,1` | Native passes `--gpu 0,1`; Compose sets `GPU` / `GPUS` |
| `VISION=cpu` | Safe on 16 GB cards (GPU vision wants ~24 GB+) |
| `MODEL=IQ2_XS` | Conservative default for **16 GB** V100s |

You **must** name both cards. Cards older than RTX 20 (compute capability below 7.5) are **not** auto-included in a layer split.

## 16 GB vs 32 GB

`nvidia-smi` on the box. Each extra card in a split also keeps its own dense weights and prompt buffers (~2 GB estimate each).

| Cards | Suggested first pack | Notes |
| --- | --- | --- |
| 2× V100 **16 GB** (this host) | `IQ2_XS` or `Q2_0`, or `coder` / `IQ1_M` | Keep `VISION=cpu` or `off` |
| 2× V100 **32 GB** | `IQ3_S` is reasonable | You may set `VISION=gpu`; still run `./scripts/plan.sh` |

A split **adds expert-cache room**, not necessarily decode speed. Strata has **not** published a measured 2× V100 layer split with the Volta kernels. Community numbers exist for single V100 (e.g. UD-IQ4_XS prompt ~1.1–1.2k tok/s on a 32 GB PCIe card).

## Setup

1. NVIDIA driver 575.51+, Docker, NVIDIA Container Toolkit.
2. This repo. **Do not copy** a Blackwell `.env` or `./data` unless you intend to reuse GGUFs and know the layouts. The Blackwell `.env` is `cuda13` + `GPU=0`; this box needs `cuda12` + `GPU=0,1`.
3. Profile:

   ```bash
   cp .env.v100.example .env
   sed -i "s/^API_KEY=.*/API_KEY=$(openssl rand -hex 24)/" .env
   ```

4. Same commands as [USAGE.md](USAGE.md):

   ```bash
   ./scripts/install-native.sh
   docker compose pull          # pulls cuda12 because of STRATA_IMAGE
   ./scripts/plan.sh            # must mention CUDA 12 / sm_70, both GPUs
   ./scripts/launch-docker.sh   # or ./scripts/launch-native.sh
   python3 scripts/test_api.py  # after health is loaded
   ```

5. If the plan says the engine does not match the card, you still have `cuda13` in `.env`. Fix `STRATA_IMAGE` and re-pull.

Native equivalent without the wrapper:

```bash
strata launch --family qwen --model IQ2_XS --gpu 0,1 --vision cpu --context 32k --yes --no-tui
```

Docker equivalent:

```bash
docker run -d --name strata --gpus all \
  -p 127.0.0.1:8080:8080 \
  --ulimit memlock=-1:-1 --shm-size 2g --stop-timeout 120 \
  -v "$PWD/data:/data" \
  -e FAMILY=qwen -e MODEL=IQ2_XS -e GPU=0,1 -e VISION=cpu \
  -e API_KEY="$API_KEY" \
  ghcr.io/niko1221/strata:0.2.8-cuda12
```

## Draft layer (MTP)

First launch also downloads the **MTP draft layer** (~5 GB). It is a small extra network from the Qwen checkpoint, not a second full model. It guesses upcoming tokens; the main model verifies them (speculative decoding). Replies are often about twice as fast. Quality of the accepted tokens is still the main model’s.

Leave it on unless you are short on memory.

## Mixed cards

A V100 plus an RTX 30/40 card forces **CUDA 12** for that model. Do not put an RTX 50 (Blackwell) in the same launch as a V100. This wrapper does not try to mix the two machines’ GPUs over the network; each PC runs its own server.

## Limits to expect

- Experimental path (community-measured, not the default RTX engine)
- Layer split is pipeline parallelism (no NVLink required)
- Two V100s help when experts do not fit one card; they may not raise tokens/s
- DeepSeek V4.1-Flash in current Strata docs is listed for RTX 30/40/50, not V100 — do not assume it
